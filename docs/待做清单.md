## 二、🔴 高优（下批做）

### 1. HTTP 接口安全边界（✅ 主体已完成，余项见下）

**2026-10-18 实测结论**：宿主 `/api` 网关有鉴权（无凭据 401），
但插件 `webServer.register()` 的路由**不在保护范围** ——
不带凭据 POST `config/set` 返回 200 且真的改了配置。

已完成（v0.4.24）：
- [x] 查清监听地址（webServer 默认 `127.0.0.1`）与鉴权边界
- [x] `readJsonBody()` 加 64 KB 累计上限（413 区分于 400）
- [x] `preview` / `selftest` 3 秒最小间隔限流（429 + retry-after）
- [x] 本地来源防护：Origin/Referer 必须本机回环、拒绝 cross-site、
      写操作强制 JSON（堵死跨站表单提交）

**剩余待做**：
- [ ] `consume` 仍用 GET 清状态（语义上应 POST）—— 已加来源防护，
      但语义仍不理想；改动需同步 client.js 与测试
- [ ] `selftest` / `preview` 仍是 GET 触发副作用 —— 同上
- [ ] 加「导出诊断」时的脱敏（见第 5 项）

**仍然存在的局限（如实记录）**：
- 不防本机进程。本机进程伪造 Origin 很容易，但它在 Windows 上本来
  就能直接读文件，不属本模块职责。

### 2. ✅ 公开测试与 CI（已完成 v0.4.25~0.4.28）

- [x] `test/` 全部公开（29 个文件）
- [x] `package.json` 加 scripts
- [x] GitHub Actions：单元测试（Node 20/22/24）+ PowerShell 语法与 BOM
      + 打包完整性 + 版本一致性
- [x] 依赖真实宿主的测试改为 `DSH_CORDIS_ENTRY` 可配置，找不到则 skip
- [x] **CI 实际绿了**（2026-10-18 验证 Node 20/22/24 全通过）

## 三、🟡 中优

### 3. 语音包存储层重构（**必须先于下载功能**）

**现状**：三处都硬编码「插件安装目录」：

| 位置 | 行为 |
|---|---|
| `index.js → hasVoiceLine` | 查 `<plugin>/sounds/voice-lines` |
| `dsh-notify.ps1` | 从插件目录找声音 |
| `tools/notify-config.ps1 → Remove-VoicePack` | 直接删插件目录里的 wav |

**问题**：下载功能要写到 `%LOCALAPPDATA%`（插件目录不可写）。
若不先改路径，会出现「下载成功但插件找不到音色」。

**目标结构**：
```
<plugin-root>/sounds/voice-lines/    只读，随 npm 安装
%LOCALAPPDATA%/dsh-notify-say/
  voice-lines/<key>/                  用户下载，读写
  packs.json                          已装包清单
```

**具体待办**：
- [ ] 新建 `lib/voice-pack-store.js`：统一查找 / 安装 / 卸载
- [ ] 查找顺序：用户目录 → 插件目录（后者兜底）
- [ ] PowerShell 播放脚本改为**接收明确路径参数**，不自己拼规则
- [ ] ZIP 解压：SHA-256 校验 + 拒绝 `../` 与绝对路径 + 先写临时目录再切换
