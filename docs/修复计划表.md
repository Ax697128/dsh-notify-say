### 第 2 批：错误漏播专项（最高优先级）

**背景**：外部审查（2026-10-19）基于 v0.4.64 源码，发现 4 个「错误没有声音」的缺陷。
**严重度高于空闲门** —— 完成提醒晚一点只影响体验，错误没提醒可能让人离开很久才发现。

| # | Bug | 证据位置 | 严重度 | 状态 |
|---|---|---|---|---|
| 2.1 | **失败被完成的 60 秒去抖压制** | `emitDone()` 里 `skipLog('debounce', psKind, ...)`，`psKind` 只进日志不参与判定 | **P0（默认配置必现）** | ⬜ |
| 2.2 | **后台 job failed 无独立播报路径** | 全文件搜不到 `'failed'`/`'killed'`；`jobs.events` 回调只调 `reevaluatePending` | **P0** | ⬜ |
| 2.3 | **缺 reason 默认 completed + 复用旧 reason** | `rec && rec.kind ? rec.kind : 'completed'`；`lastTurnEnd` 只在卸载时 clear | **P0** | ⬜ |
| 2.4 | **spawn 不检查退出码** | `stdio:'ignore'` + `child.once('exit', settle)`，settle 只减计数 | P1 | ⬜ |
| 2.5 | `tts-speak.ps1` 的 MCI play 返回码未检查 | ps1 里 `play ... wait` 后未判断 | P1 | ⬜ |

**修法要点**：
- 去抖分级：`fail` 不被 `completed` 压制，反之亦然（按 kind 分桶记时间）
- 相同错误事件用稳定 ID 去重，防重复播报
- 后台 job failed → 独立失败播报（关联 job id 去重）
- 主回合与子任务报同一失败 → 合并为一次
- 缺 reason → 引入「原因未知」状态，**不默认 completed**
- `lastTurnEnd` 按轮次消费（处理完删除）
- spawn 记录：启动成功 / 失败 / 退出码非零，失败时有限次降级到系统蜂鸣

**测试（审查要求 A~L 共 12 条）**：
| 编号 | 场景 |
|---|---|
| A | 完成通知后 25 秒发生错误，失败提醒仍能触发 |
| B | 连续两次同一错误事件，只提醒一次 |
| C | 后台 job failed、主回合未产生 error，仍能提醒 |
| D | 后台 failed 与主 Agent 随后报告同一失败，不重复 |
| E | turn/end error 晚于 agent/status idle |
| F | 缺失 reason 时，不误播 completed |
| G | 上一轮 error 不污染下一轮 completed |
| H | PowerShell 启动失败 / 退出码非零 / TTS 播放失败 |
| I | 4 个以上通知并发时，重要错误不被静默丢弃 |
| J | max-tokens / blocked / aborted 配置行为正确 |
| K | 子任务返回造成主 Agent 短暂 running 时，pending 不丢 |
| L | 本地工作树全部空闲后，最终通知恰好一次 |

## 验证要求（不可跳过）

### 单元测试（确定性模拟）
必须覆盖：
- 无后台任务 → 播一次
- 有子代理 → 先不播，结束播一次
- 子代理返回导致 running → pending 不丢
- **内部续跑 lastTurn 递增 → pending 不丢**
- 多次 running/idle 切换 → 只播一次
- 用户新消息（不可识别）→ 不误取消
- 后台结束但主会话仍处理 → 不提前播
- 超时仍运行 → 不宣称完成
- 失败/批准/提问 → 不回归
- 重复事件 → 不重复播
- 卸载 → 无残留定时器

### 真机集成测试（必须）
| 编号 | 场景 | 判据 |
|---|---|---|
| R1 | 子任务在跑 | 日志有 `[skip] idle-gate-hold`，**且听不到声音** |
| R2 | 子任务全结束 | 日志有 `[flush] idle-gate ... worktree-idle`，**且听到一次** |
| R3 | 超时仍跑 | 日志有进度提醒，**文案不含"完成"** |

**测试前必检三项**（我踩过坑）：

## 踩坑记录（本轮实测）

| # | 坑 | 教训 |
|---|---|---|
| 1 | `jobs.list(agent)` 传对象，官方要 `agent.id` | 查宿主用法，别凭类型猜 |
| 2 | `onJobsChanged` 方法不存在，订阅被静默跳过 | 用探针列真实方法，别假设 |
| 3 | 空闲门单测全绿但功能坏 | **测了纯函数，没测调用契约** → 加静态断言 |
| 4 | `lastTurn` 递增被当"用户新消息" | 间接信号不能当证据 |
| 5 | 测试前忘删哨兵 → 任务秒退 → 测不到挂起 | 测试前必检三项 |
| 6 | 用 `powershell.exe` 查残留，实际是 `pwsh.exe` | 看 job id 前缀判断 |
| 7 | 查询命令自身含关键词，被自己匹配到 | 排除自己的命令行 |
| 8 | 同一 `agent/status` 事件既 reevaluate 又 handleDone → 播报两次 | 一个事件只走一条播报路径 |
| 9 | 后继轮次（turn 3）与挂起轮次（turn 2）各播一次 | 同会话挂起项要**合并**，不能各播 |
| 10 | 按行号插入代码，插错位置/挤成一行 | 多行改动用**整段函数替换** |
| 11 | 测试前不清哨兵（三次） | 提示词里加 `Remove-Item $stop` 自清 + 输出 `WAITED_SECONDS` 证明真等待 |
